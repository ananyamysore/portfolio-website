# Ananya Sukruta Mysore — Portfolio

Single-page personal portfolio. Everything lives in `index.html` (no build step).

**Run locally:** open `index.html` in a browser.

**Deploy with GitHub Pages:** Settings → Pages → Source: *Deploy from a branch* → `main` / root.

To use a photo in the hero, put `me.jpg` next to `index.html` and replace the `<canvas id="cells">` element with
`<img src="me.jpg" alt="Portrait of Ananya Sukruta Mysore">`.
